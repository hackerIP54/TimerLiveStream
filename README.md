# Countdown Timer for OBS / TikTok

This project provides a **Unix Timestamp countdown timer** for live streaming.  
It can be used in **OBS Studio** or **TikTok Live Studio** as a browser source or downloaded as a standalone HTML file.

---

## English Version

### Features

- Enter a Unix Timestamp from [https://www.unixtimestamp.com](https://www.unixtimestamp.com)
- Optional design selection (Standard / Glow)
- Generates a URL that can be used directly in OBS/TikTok
- Option to download the HTML file
- Countdown auto-starts if the URL contains a timestamp

### How to Use

1. Go to  GitHub Pages URL:
3. 2. Enter your Unix Timestamp (example: `1735689600`) and select a design.
4. Click **Generate Countdown**.
5. Copy the generated URL, e.g.:
6. Use it as a **Browser Source** in OBS Studio or TikTok Live Studio.
5. Optional: Click **Download HTML** to save a local copy.

### OBS / TikTok Settings

- Add a **Browser Source**  
- Paste the generated URL  
- Set Width/Height (example: 1920x200)  
- Ensure **Transparent Background** is enabled if your design uses it
